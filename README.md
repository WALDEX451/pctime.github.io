# 🖥 Welcome to PC Time

PC Time is a website about the history and evolution of computers through time.

The goal of this project is to explore how computers changed from large early machines to modern devices and futuristic concepts.

This website is made for everyone interested in:
- computer history
- retro technology
- classic systems
- old hardware
- vintage devices
- futuristic computers
- AI technology
- and the digital future.
